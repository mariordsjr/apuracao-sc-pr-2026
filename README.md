# Apuração 2026 — SC + PR

Site estático, pronto para publicação em GitHub Pages ou outro host HTTPS.

## Recursos
- Santa Catarina e Paraná
- Governador, Senador, Deputado Federal e Deputado Estadual
- Busca por candidato ou partido
- Atualização automática a cada 30 segundos
- Botão de atualização manual
- Dados diretamente dos arquivos públicos do TSE

## Publicação
1. Crie um repositório no GitHub.
2. Envie `index.html`.
3. Em Settings > Pages, escolha a branch principal e a pasta `/root`.
4. Abra a URL do GitHub Pages.

O TSE disponibiliza publicamente os arquivos de resultados e permite soluções próprias de divulgação, respeitando os limites técnicos. O código da eleição estadual usado aqui é 6259.
